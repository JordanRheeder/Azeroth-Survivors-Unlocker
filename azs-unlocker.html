Azeroth Survivors Unlocker

Runs entirely in this page, offline. Nothing is uploaded. Close the game first.

1 Unlock everything in your save

Pick your characters.txt. On Windows it is in %APPDATA%\wenilla-rogue\ (paste that into the Explorer address bar). With Proton/Linux it is in <prefix>/drive_c/users/steamuser/AppData/Roaming/wenilla-rogue/.

  • every zone opened and beaten for all 9 classes, Naxxramas included
  • all gear pieces, every ring/trinket/amulet in the codex
  • every achievement, which unlocks the perks, companions and tabards behind them
  • enough talent experience for every talent point
Then what?

Make a copy of your old characters.txt somewhere safe, then replace it with the downloaded one (it lands in your Downloads folder; if the browser names it characters (1).txt, rename it to characters.txt). Start the game.

2 Game patches optional

Choose what to change, then pick AzerothSurvivors.exe from the game folder. Only the exact version these were made for is accepted (an exe already patched here is fine).

Then what?

Rename the original to AzerothSurvivors.exe.orig as a backup, then put the downloaded AzerothSurvivors.exe in the game folder. If the game updates itself, patch again.

To undo: put your backup characters.txt / AzerothSurvivors.exe.orig back.
